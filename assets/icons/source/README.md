# App icon source

`icon-catarina.jpeg` is the original artwork. `icon-catarina.svg` is the
vectorized source. `../catarina-badge.svg` is the production icon: square
512x512, cream rounded badge with a dark border, and optimized with SVGO.

Keep the source files when the icon changes; they are not installed or bundled
into the application. Before a public release, confirm that the artwork is
original or that its license allows redistribution under GPL-3.0-or-later, and
record the author/attribution here.
